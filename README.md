# 🎲 DevSorteios

O **DevSorteios** é uma aplicação web simples, rápida e intuitiva para sorteio de números aleatórios dentro de um intervalo personalizado.

---

## 🚀 Funcionalidades

* **Definição de Intervalo:** Escolha o número mínimo e máximo para realizar o sorteio.
* **Geração Aleatória:** Processamento rápido e imparcial via JavaScript.
* **Interface Simples:** Design limpo e direto ao ponto.
* **Responsividade:** Funciona bem tanto em desktops quanto em dispositivos móveis.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização visual (com fonte *Roboto* via Google Fonts).
* **JavaScript:** Lógica de sorteio e manipulação dos dados de entrada.

# 🎲 DevSorteios

**DevSorteios** is a simple, fast, and intuitive web application for drawing random numbers within a custom range.

---

## 🚀 Features

* **Range Selection:** Choose the minimum and maximum numbers for the draw.
* **Random Generation:** Fast and unbiased processing using JavaScript.
* **Simple Interface:** Clean and straightforward design.
* **Responsiveness:** Works well on both desktop and mobile devices.

---

## 🛠️ Technologies Used

* **HTML5:** Semantic page structure.
* **CSS3:** Visual styling (using the *Roboto* font via Google Fonts).
* **JavaScript:** Draw logic and input data handling.
